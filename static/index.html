ရုပ်ရှင်ဗီဒီယိုကို အလိုအလျောက် Recap / Dubbing ပြုလုပ်ပေးသည့် ကိရိယာ

ဗီဒီယို ရွေးရန်

ပြုလုပ်လိုသော ရုပ်ရှင်ဗီဒီယိုဖိုင်ကို ရွေးပါ။

ဒီနည်းလမ်းမှာ ဗီဒီယိုမရွေးလည်း ရပါသည် (အရောင်နောက်ခံဖြင့် ထုတ်ပေးမည်)။
မူရင်းအသံကို မပြောင်းဘဲ ဗီဒီယိုနဲ့ ကိုက်ညီအောင် စာတန်းတစ်ကြောင်းချင်း ထည့်ပေးမည်။ ဒီလုပ်ဆောင်ပုံမှာ အောက်က “အသံ (Voice)” အပိုင်းကို မသုံးပါ။
အဆင့်များ - ① Whisper က စကားကို စာသားပြောင်း ② Gemini က Recap စာသားရေး ③ အသံထုတ် ④ ဗီဒီယိုနှင့် ပေါင်းစပ်။ ဇာတ်ကားရှည်ရင် CPU မှာ အချိန်ကြာပါမည်။
⚠ faster-whisper မသွင်းရသေးပါ။ pip install -r requirements.txt ကို run ပါ။
⚠ Gemini API key မထည့်ရသေးပါ။ .env ဖိုင်ထဲ GEMINI_API_KEY ထည့်ပြီး server ကို ပြန်စပါ။ မထည့်ရင် မူရင်းစကားအတိုင်းသာ ထွက်မည် (ဇာတ်လမ်းပြန်ရေးမပေးပါ)။

အသံ (Voice)

ဗီဒီယိုမှာ ပြောပေးမည့် အသံကို ရွေးပါ။

အသံပိုင်ရှင်ကိုယ်တိုင်က အပေါ်ကစာကို အတိအကျ ဖတ်ပြီး နမူနာနှင့် မိုက်ခရိုဖုန်းတစ်ခုတည်းဖြင့် အသံသွင်းရပါမည် (Google ၏ စည်းမျဉ်း)။ ကိုယ့်အသံ သို့မဟုတ် ခွင့်ပြုချက်ရထားသော အသံကိုသာ သုံးပါ။ Voice Clone ဖွင့်ထားစဉ် အောက်က Model နှင့် Voice ကို မသုံးပါ။
⚠ Voice Clone အတွက် GEMINI_API_KEY လိုအပ်ပါသည်။
▶ နှိပ်ပြီး အသံနမူနာ နားထောင်ပါ။ ✎ နှိပ်ပြီး အသံကို ကိုယ်ပိုင်အမည်ပေးနိုင်ပါသည် (ဒီ browser ထဲမှာသာ သိမ်းမည်)။

စာတန်းထိုး (Subtitles)

ဗီဒီယိုပေါ်မှာ စာတန်းကို တိုက်ရိုက်ထည့်ပေးမည်။ နေရာကို အောက်က Preview ထဲမှာ ဆွဲရွှေ့နိုင်ပါသည်။

မြန်မာစာတန်းအတွက် FFmpeg run နေသောကွန်ပျူတာမှာ မြန်မာ font လိုပါသည်။ “Noto Sans Myanmar” သို့မဟုတ် “Padauk” သွင်းပါ၊ ဒါမှမဟုတ် .ttf ဖိုင်ကို main.py ဘေးက fonts/ folder ထဲ ထည့်ပြီး ဒီမှာ ရွေးပါ။

Auto Edit

ဗီဒီယိုဖိုင် ရွေးထားမှသာ အသုံးဝင်ပါသည်။ မူရင်းဗီဒီယိုကို အနည်းငယ်ပြင်ဆင်ပေးသည်။

ဗီဒီယိုကို အခါအားလျော်စွာ ခဏရပ်ပြီး ကျန်အပိုင်းကို အနည်းငယ်မြန်စေသည်။ စုစုပေါင်းအချိန် မပြောင်းသဖြင့် အသံနှင့် မလွဲပါ။

Logo

ဗီဒီယိုပေါ်မှာ ပုံ logo နှင့် စာသား logo ကို ထည့်နိုင်ပါသည်။ နေရာကို Preview ထဲမှာ ဆွဲရွှေ့နိုင်ပါသည်။

Cover / Poster

ဗီဒီယိုထဲက အကြည်ဆုံး frame ကို Poster ပုံအဖြစ် ရွေးပြီး ခေါင်းစဉ်စာတန်း ရေးပေးသည်။ ဒီ Poster ပုံကိုပဲ ဗီဒီယိုအစမှာ Cover အဖြစ် အလိုအလျောက် ထည့်ပေးနိုင်သည်။ ပုံစံ၊ ခေါင်းစဉ်၊ စာလုံးကို အောက်မှာ တစ်ခါတည်း သတ်မှတ်ပါ။

Video Live Shape Visualizer

ဗီဒီယိုအရွယ်အစား ရွေးပါ၊ အသံနှင့်အတူ လှုပ်ရှားမည့် ပုံသဏ္ဍာန်ကို သတ်မှတ်ပါ၊ ပြီးလျှင် အောက်က Preview မှာ ကြည့်ပါ။

ဗီဒီယိုပါလျှင် နောက်ခံက ပုံသဏ္ဍာန်နောက်က အကွက်ဖြစ်သည်။ ဗီဒီယိုမပါလျှင် (စာသားသက်သက်) ဗီဒီယိုတစ်ခုလုံး၏ နောက်ခံဖြစ်လာမည်။
